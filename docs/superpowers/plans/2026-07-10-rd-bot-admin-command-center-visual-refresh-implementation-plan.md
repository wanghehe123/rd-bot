# RD-Bot Admin Command Center Visual Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Repository instructions prohibit commits unless the user explicitly requests them, so this plan does not include commit steps.

**Goal:** Turn all 16 RD-Bot admin routes into a cohesive, responsive “研发指挥中心” while preserving the current API, routing, task control, attachment, template, AI draft, and alert behavior.

**Architecture:** Keep the existing React/Vite application and both component APIs, but give them one token contract and one admin presentation layer. `globals.css` remains the Tailwind/shadcn foundation; `styles.css` becomes the authoritative `--admin-*` shell and legacy-component stylesheet loaded after Tailwind. Behavioral changes are limited to mobile navigation, truthful Dashboard metrics, accessibility, and layout stability.

**Tech Stack:** React 18, TypeScript, React Router 6, Vite 6, Tailwind CSS 3, Radix/shadcn components, Lucide icons, Node test runner, Spring Boot static hosting.

```tsx
const [collapsed, setCollapsed] = useState(false);
const [mobileSidebarOpen, setMobileSidebarOpen] = useState(false);

useEffect(() => {
  setMobileSidebarOpen(false);
}, [location.pathname]);

useEffect(() => {
  const handleKeyDown = (event: globalThis.KeyboardEvent) => {
    if (event.key === "Escape") setMobileSidebarOpen(false);
    if ((event.metaKey || event.ctrlKey) && event.key.toLowerCase() === "k") {
      event.preventDefault();
      inputRef.current?.focus();
    }
  };
  window.addEventListener("keydown", handleKeyDown);
  return () => window.removeEventListener("keydown", handleKeyDown);
}, []);
```
